Raw data folder

The AMLSim CSV files are not stored in this repository because of their size.

To re-run the full pipeline (python -m src.run_pipeline):
1. Download the IBM AMLSim dataset from Kaggle.
2. Place transactions.csv, accounts.csv and alerts.csv in this folder (data/raw/).

The Streamlit app does not need these files: trained models, saved scenarios and results are already included in the repository.
